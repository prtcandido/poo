8. Qual é a diferença conceitual e prática entre os conceitos de 'Sobrecarga' (Overloading) e 'Sobrescrita' (Overriding) em Java?

A. Sobrecarga acontece entre classes diferentes ligadas por herança, enquanto a sobrescrita acontece na mesma classe.
B. Sobrecarga altera o comportamento de um método na classe filha mantendo os mesmos parâmetros, enquanto a sobrescrita exige mudar o nome do método.
C. Ambos os termos se referem estritamente à alocação de memória estática para tratamento de Threads.
D. Sobrecarga (Overloading) permite ter métodos com o mesmo nome na mesma classe, mas com assinaturas (parâmetros) diferentes; já a Sobrescrita (Overriding) substitui a implementação de um método herdado da superclasse na subclasse, mantendo exatamente a mesma assinatura.
E. A sobrescrita é exclusiva de tipos primitivos, enquanto a sobrecarga se aplica apenas a Interfaces complexas.

Resp.: D

  public int mx() { return "X"; }
  public int mx(int a) {...} // Sobrecarga
}

class C2 extends C1 {
  public int mx() { return "Y";} // Sobrescrito
}
